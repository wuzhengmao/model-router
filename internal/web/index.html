基础配置

回退参数

失败阈值 ≥1；回退时长如 5m / 30s / 1h（必须 >0）；最低吞吐 ≥0，填 0 表示禁用吞吐判定，留空使用默认 30；空闲超时如 30s，填 0 表示禁用空闲超时判定，留空使用默认 30s。

提供商实例

各组内实例顺序即回退候选顺序（越靠前越优先），拖动实例标题可在组内调整顺序。「查询模型」会请求上游 /v1/models；若上游不支持，请手动输入模型名。
